# Chap34 — Frontend (Next.js)

## راه‌اندازی

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

سپس http://localhost:3000 را باز کن. بک‌اند FastAPI باید همزمان روی
http://localhost:8000 در حال اجرا باشد (نسخه به‌روزشده‌ی بک‌اند، همونی که
با `/api/...` کار می‌کنه).

## مسیر کامل کاربر (هماهنگ با API جدید)

```
/  →  /capture  →  /processing (تشخیص جنسیت)  →  /gender-settings
   →  /generating (تولید نهایی)  →  /result
        ↓ (سفارش چاپ)
/checkout/phone  →  /checkout/otp
   →  /checkout/print (سایز/تعداد/کاغذ + قیمت زنده)
   →  /checkout/address
   →  /checkout/summary (خلاصه سفارش + پرداخت با هم)
        ↓
/orders/[id]/tracking
```

## چیزهایی که در این نسخه دمو فیک هستند

| بخش | وضعیت فعلی |
|---|---|
| تشخیص جنسیت | بک‌اند تصادفی حدس می‌زند؛ کاربر می‌تواند در `gender-settings` دستی عوض کند |
| تولید عکس نهایی | بک‌اند فقط عکس اصلی را کپی می‌کند |
| OTP | همیشه `1234` |
| پرداخت | `init` و `callback` بین خودشونه، درگاه واقعی نیست |
| قیمت‌گذاری | **واقعی نیست فیک نیست** — از `GET /api/print/pricing` می‌آید و سمت سرور محاسبه می‌شود |

## نکات فنی

- وضعیت چندمرحله‌ای فرم سفارش چاپ (سایز/تعداد/کاغذ/آدرس) بین صفحات با
  `lib/draft.ts` (localStorage) رد و بدل می‌شود تا آدرس URL شلوغ نشه.
- `photo_id` اولیه (همون عکس آپلودشده) در کل مسیر معتبر می‌مونه، پس دکمه
  «ویرایش تنظیمات» توی صفحه نتیجه می‌تونه بدون آپلود دوباره، کاربر رو به
  `gender-settings` برگردونه و دوباره `generate` بزنه.
